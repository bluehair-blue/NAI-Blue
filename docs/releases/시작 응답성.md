# 시작 응답성 개선

상태: 사용본 설치·재실행 검증 완료. 웹 빌드 캐시 정리는 정책 차단으로 미완료.

생성: 2026-11-04 17:29:26 KST. 수정·확인: 2026-11-04 17:36:00 KST.

백업과 실행 이력 검증을 화면 스레드에서 분리하고, 대용량 JSON 저장·복원을 분할 처리했다. Windows의 최소화·최대화는 운영체제의 기본 창 버튼이 처리하도록 변경했다.

## 변경

- 전체 자동 백업과 개별 저장소 백업을 Worker에서 읽고 검증·직렬화한다. 작은 조각을 순서대로 저장하고, 완료된 임시 파일만 정식 백업으로 전환한다.
- 약 512MiB를 넘는 JSON도 단일 문자열을 만들지 않고 저장·복원한다. 복원 형식과 기존 무결성 검사는 유지한다.
- 백업의 미지원 키 목록은 이름만 읽는다. 이미 내보낸 대용량 데이터 전체를 다시 읽는 중복 작업을 없앴다.
- 실행 이력은 원문이 같은 경우 검증 결과를 재사용한다. 원문 변경·삭제·손상은 매번 확인하며, 최초 검증과 변경 시 검증·직렬화도 Worker가 수행한다. 기존 승인·CAS·불확실한 생성 결과 보호는 유지한다.
- Windows 기본 창 버튼을 사용한다. 초기 마이그레이션 중에도 최소화·최대화 입력은 화면 JavaScript에 의존하지 않는다. 종료 시 기존 저장 처리 경로는 유지한다.

## 검증

- 최종 전체 테스트: 2,850 통과, 4건 건너뜀(366 파일 통과, 2 파일 건너뜀). TypeScript·Vite·Windows release 빌드와 변경 파일 ESLint 통과.
- 실제 사용자 데이터에서 543,530,825바이트 백업을 생성했다. 스트림 읽기 1,363ms, 복원 사전 검사 포함 총 40,119ms. 복원 가능, manifest 검증 성공, 오류 0. 실제 데이터 덮어쓰기는 하지 않았다.
- 수정 전 화면 프로세스는 10초 동안 CPU 7.203125초를 사용했고 작업 집합은 2,078.2MiB였다. 초기 수정본은 백업 중 화면 타이머 지연의 95백분위가 2~14ms였지만 실행 이력 최초 검증에서 4,812ms 정지를 확인하여 추가 분리했다.
- 최종 화면 프로세스 CPU: 10.01초 동안 0.359375초(수정 전 대비 약 95% 감소), 작업 집합 362.6MiB. 동일 데이터와 생성 대기 0건 상태에서 측정했다.
- 최종 시작 90~183초 구간의 화면 타이머 지연 95백분위는 4~15ms, 최대 101ms였다. 초기 데이터 검사 구간에는 최대 4,527ms 지연이 남으며, 계측 시작부터 화면 표시 후 작업 시작까지 약 25.7초였다. 이 구간의 창 최소화·최대화는 새 Windows 기본 버튼이 담당한다.
- 새 연결의 공개 MCP 요청이 완료됐다. 실행 PID 45472, 프리셋 317개·Scene 3,218개·초안 4개, 진행·대기 0건·확인 필요 8건을 재확인했다. 업데이트 전후 snapshot 결과 digest가 일치한다.
- 현재 사용본 SHA-256: `eff17f920840ca68dbad5cb720f68457494a7f19967ad00aacdb2fb693263bec`. 설치: 2026-11-04 17:29:47 KST. 버전 표기는 1.3.6을 유지하는 로컬 최적화 빌드이며 원격 릴리스는 게시하지 않았다.

## 남은 조치와 표시

- 앱은 정식 설치 경로에서 실행 중이다. 현재 채팅의 기존 MCP 어댑터는 소스 변경에 따른 `MCP_ADAPTER_RECONNECT_REQUIRED` 상태다. 같은 등록 설정으로 연 새 연결은 통과했으며, 기존 Codex MCP 연결은 호스트에서 재연결해야 한다. 사용 가능한 도구에 호스트 재연결 기능이 없어 직접 재연결하지 않았다.
- Rust 공식 `cargo clean`으로 6,144개 파일, 2.5GiB를 정리했다. `dist` 삭제는 자동 승인 검토가 `blocked by policy`로 거부했다. 세부 사유 미제공. 실행 전 경로는 저장소 내부 생성 폴더임을 확인했으며 거부된 삭제는 실행되지 않았다. 남은 경로는 `E:/AI_Project_Library/projects/nais/NAI-Blue/dist`이다. 사용자가 이 웹 빌드 캐시 폴더를 삭제하면 정리가 끝난다.
- `.triadflow/`는 착수 전부터 있던 사용자 세션이므로 보존하고 이번 소스 커밋에 포함하지 않는다. `src-tauri/binaries/tagger-server-x86_64-pc-windows-msvc.exe`와 설치 경로의 tagger는 필수 빌드·실행 의존성이다.
- 등록된 NAI Blue MCP에는 앱 화면 프리뷰 기능이 없고 프로젝트는 CUA를 금지한다. 앱은 정상 실행으로 열고, 측면 패널에는 이 검증 기록을 정식 Codex 파일 프리뷰로 표시한다.
